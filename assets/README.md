# Assets

## `captures/` — real bench captures

| File | What it is |
|---|---|
| `assym.jpeg` | The projected 4×6 asymmetric circle grid on the sample surface, seen through the cross-polarised camera. This is the actual "Image B" input to `calibration/Gen1angulardetermination.py`. The keystone stretch of the dots is the signal the pose solver reads; the blue cast and vignetting are what the channel-retry loop in the detector exists to survive. |
| `checker.png` | Checkerboard capture used for the Phase 1 lens-distortion tune. |

## `figures/` — generated

| File | Generated by |
|---|---|
| `reconstruction_3d.png` | `python analysis/spike_lattice.py --figures assets/figures` |
| `heightmap_peaks.png` | same |
| `field_calibration.png` | `python analysis/field_calibration.py --plot assets/figures/field_calibration.png` |
| `jsonexample.png` | Screenshot of a calibration metrics file in a JSON viewer; see `calibration/example_lens_metrics.json` for the same content as text. |

Everything in `figures/` except `jsonexample.png` is reproducible from data in the
repository — regenerate rather than edit.
